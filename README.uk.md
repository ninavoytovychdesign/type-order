# Type Order – аудит і порядок у типографіці

Плагін для Figma, версія 1.0. Аналізує текст у макетах, показує звіт, зводить кілька шрифтів до одного й створює текстові стилі з того, що вже є в макетах. Інтерфейс англійською та українською.

## Як запустити

Збірка вже лежить у `dist/`, тож встановлювати нічого не треба.

1. Розпакуй архів.
2. Відкрий **Figma Desktop** і будь-який дизайн-файл.
3. Вибери **Plugins → Development → Import plugin from manifest…** і вкажи `manifest.json` з цієї папки.
4. Запускай через **Plugins → Development → Type Order**.

Якщо раніше імпортувала генеративну версію Type Order, ця відкриється як окремий плагін.

Якщо змінюєш код:

```bash
npm install
npm run build     # dist/code.js і dist/ui.html
npm run check     # типи + тести + збірка
```

## Що вміє

**Шапка**
- Що перевіряти: виділення, поточна сторінка або всі сторінки.
- Перемикач EN / UA. Вибір запамʼятовується між запусками.
- Плагін нічого не змінює, поки не натиснеш кнопку дії. Кожна дія скасовується одним Cmd/Ctrl+Z.

**Огляд**
- Кількість текстових шарів, шрифтів, розмірів і унікальних комбінацій типографіки.
- Частка тексту, привʼязаного до стилів.
- Шрифти з накресленнями, розміри, накреслення, міжрядкові інтервали. Клік на шрифт чи чип виділяє ці шари на канвасі.
- Майже однакові розміри (наприклад, 15 і 16) підсвічуються як кандидати на обʼєднання.
- Невідповідності, кожна з поясненням і виділенням шарів:
  - текст без стилю;
  - стиль, перебитий вручну (з кнопкою «Скинути до стилю»);
  - кілька стилів в одному шарі;
  - шрифт, якого немає на компʼютері;
  - бібліотечні стилі.
- «Вивести звіт на канвас»: фрейм з автолейаутом праворуч від макетів, з підсумком, шрифтами, розмірами, невідповідностями й запропонованими стилями зі зразками тексту.

**Шрифти**
- Вибираєш шрифт, який залишити: один з наявних у файлі або будь-який встановлений.
- Для кожного накреслення інших шрифтів плагін пропонує найближче за вагою, з тим самим нахилом (Manrope SemiBold → Inter Semi Bold). Кожну пару можна змінити.
- Локальні текстові стилі з цим шрифтом оновлюються самі, тож текст за ними змінюється без перебивання стилю.
- Після заміни плагін показує шари, де змінились переноси, і шари з фіксованим розміром, у які текст може не вміститись.

**Стилі**
- Групує текст без стилю за шрифтом, накресленням і розміром. Майже однакові розміри склеює: центром стає найуживаніший розмір, інтервал береться з найуживанішого варіанта. Склеювання можна вимкнути.
- Пропонує назви за роллю (`Heading/H1`, `Body/M`, `Caption/S`) або як у коді (`text-body-m`). Назви редагуються, зайві стилі вимикаються галочкою.
- Якщо у файлі вже є стилі, текст, що з ними збігається або дуже близький, привʼязується до наявних, а не до нових.
- Створює стилі й за галочкою одразу привʼязує до них текст. Жирне слово в реченні лишається як є, якщо його комбінація не увійшла в стиль.

**Безпека змін**
- Текст у головних компонентах за замовчуванням не змінюється. Окрема галочка вмикає це, бо зміни дійдуть до всіх інстансів.
- Бібліотечні стилі не редагуються, лише показуються.
- Шари з відсутнім шрифтом пропускаються: Figma не дозволяє їх змінювати.
- Приховані шари не аналізуються.
- Плагін працює без мережі (`networkAccess: none`).

## Обмеження

- Склеювання розмірів може зменшити частину тексту, наприклад 14 → 13. Панель показує «з розмірів 13, 14», тож це видно до застосування.
- Назви стилів – евристика за розміром і вагою. Їх варто переглянути перед створенням.
- Після заміни шрифту плагін ловить зміну переносів лише в тексті з автовисотою чи автошириною. У фіксованих текстових блоках він лише попереджає.
- Змінні для розмірів і доступність (контраст, мінімальний розмір) – наступні версії.

## Перевірено

- 32 автотести: ядро (накреслення, групування, назви, звіт), повнота й множина словника UA/EN, і робота з файлом на імітації Figma API (аналіз, заміна шрифтів, створення й привʼязка стилів, скидання правок).
- Панель відкрито в Chromium з даними, схожими на Numa, обома мовами. Помилок немає, повідомлення до коду плагіна правильні.
- Перший запуск у Figma варто робити на копії файлу: аналіз сторінки, заміну одного шрифту, створення 2–3 стилів і звіт на канвасі.

## Community

Подано в Figma Community, очікує на рев'ю. Іконка 128×128 і обкладинка 1920×1080 – у `assets/`.

Опис (EN):

> Type Order audits the typography in your designs and helps you clean it up. See every font, size, weight and line height in one report, find text without styles or with overridden styles, replace several fonts with one, and turn the text you already have into a set of text styles – with names by role or code-style. Works offline. Nothing changes until you confirm. Interface in English and Ukrainian.

## Будова коду

```
src/
  core/          – логіка без Figma, покрита тестами
    spec.ts      – опис типографіки, порівняння, формат
    fonts.ts     – вага накреслення, підбір відповідника
    stats.ts     – звіт, невідповідності, вибірки шарів
    scale.ts     – групування в пропозиції стилів, збіг з наявними
    naming.ts    – назви стилів
    i18n.ts      – словник EN/UA, множина
    protocol.ts  – повідомлення між панеллю й плагіном
  figma/
    scan.ts      – обхід тексту, видимість, інстанси й компоненти
    apply.ts     – заміна шрифтів, стилі, скидання правок
    report.ts    – звіт фреймом на канвасі
  ui/            – панель (template.html + ui.ts, збирається в dist/ui.html)
  main.ts
tests/
```
